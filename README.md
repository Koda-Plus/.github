# .github

Organisation-level defaults for **[Koda Plus](https://github.com/Koda-Plus)**.

- [`profile/README.md`](profile/README.md) — the public profile page rendered at [github.com/Koda-Plus](https://github.com/Koda-Plus).
- `profile/assets/` — KODA+ wordmark, light and dark variant (the `+` keeps the malachite `#26D07C` gradient).

Edit `profile/README.md` and the org page updates on push.
